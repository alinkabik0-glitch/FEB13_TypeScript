# Инструкция по запуску Backend сервера

1. Убедитесь, что у вас установлен Node.js (версия 14+) и Yarn.
2. Перейдите в папку `backend`.
3. Установите зависимости: `yarn install`
4. Запустите сервер командой: `node server.js`
5. Сервер будет доступен по адресу: http://localhost:3001
6. База данных SQLite (`vacancies.db`) создастся автоматически при первом запуске.

## Запуск Frontend

1. Перейдите в папку `frontend`.
2. Установите зависимости: `yarn install`
3. Запустите проект: `yarn start`
4. Откройте http://localhost:3000 в браузере.
